# Small delivery fixtures

black.mp4 is a 16×16 black H.264 frame; tone.wav is 0.05 seconds of mono PCM at
8 kHz. Generated locally with FFmpeg for deterministic MIME, native-control markup
and range delivery tests. Tests consume the committed bytes and do not require
FFmpeg. These are test assets, not a runtime transcoding dependency or a browser
codec acceptance claim.
