# @wydgit/stream

Canonical library `wydstream`, implementation 0.1.0-alpha.2, API 1.0.0.
Trusted App-scoped media metadata, bounded upload, local binary storage, authorized
streaming and recovery. No ordinary package receives native streams or paths.

See [WydStream documentation](../../docs/wydstream.md) and the separate
[installable UI package](../../examples/media/README.md).
