Development focus: WydClient → WBasic/SEWN
Wydgit 0.3 initially focused on WydClient and portable browser-side Wydgit execution.
During application-level testing, the Taskboard example exposed gaps in WBasic and SEWN that required application developers to invent workarounds for otherwise routine operations.
These limitations demonstrated that expanding WydClient before stabilizing the shared execution language would multiply implementation and compatibility work.
Development therefore temporarily shifted toward completing WBasic's core language features and canonical SEWN operations.
This is not an abandonment of WydClient. It is a prerequisite investment in the common execution model that WydClient, Wydgine, and future language dialects will share.
The WBasic/SEWN 0.9 milestone begins a structured sequence of language-completion work.
