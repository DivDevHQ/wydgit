Branch: `develop/0.3`. First language extension after the WBasic rebrand.

Future design: `docs/wbasic-language-ref.md` (later milestones remain proposals).

## Architectural decisions

- A canonical `select` statement stores one selector and ordered case/test arrays.
  Lowering to repeated IF expressions would risk repeated selector effects; a
  hidden source variable would consume variable capacity and complicate scope.
- `CASE value` uses existing strict scalar equality. `CASE IS < value` (and the
  other comparison operators) is relational. `CASE IS reference` / `CASE IS NOT
  reference` is explicitly nullable Wydgit identity. Comma-separated tests may mix
  forms only when their operand contracts agree. Ranges are deferred.
- General `IS` / `IS NOT` lower to a separate `identity` expression, never a new
  binary operator in older schemas. Existing right-literal NULL tests keep their
  0.6 representation and data semantics. CASE IS NULL uses identity in 0.9.
- Identity resolves guarded trusted adapters to their live underlying nodes.
  Trusted host handles without adapters use object identity after existing handle
  validation. Fresh execution-token wrappers, repeated authorized traversal and
  procedure frames may describe the same object. Equal public IDs never suffice.
  No serialized or invocation-crossing identity contract is introduced.
- Both identity operands are guarded, even with NULL. Selection guards its
  selector even for ELSE-only branches. Foreign contexts, stale/invisible handles
  and consumed drafts cannot use identity to regain authority or bypass lifetime.
- Value comparison shares the existing interpreter comparison routine. There is
  no coercion, Array/Object equality, reflection or reference discovery.
- Each inspected branch/test consumes steps in addition to expression evaluation.
  Selected bodies count nesting; all existing counters and deadlines remain shared.
  Unmatched bodies and tests after a match do not execute.
- CASE is contextual rather than newly reserved globally: previously valid source
  identifiers named case remain accepted outside selection grammar. Earlier wire
  schema definitions and reserved-name sets remain unchanged.
- Branch declarations follow existing IF rules. Functions may prove total return
  through SELECT only with ELSE and returning bodies in every branch. Existing
  RETURN, STOP, EXIT FOR and TRY/FINALLY propagate without alternate execution.

## Limitations and next milestone

The standalone WydClient bootstrap has no portable SEWN executor; this milestone
uses the existing shared Wydgine/event execution paths. Browser-native execution
is not claimed. No range CASE syntax or implicit structural equality is supported.
All explicit exclusions remain deferred. Proposed next milestone: WBasic/SEWN
0.10 numeric foundations, with Integer/Float, literal inference, checked arithmetic
and numeric operator contracts resolved before implementation.
