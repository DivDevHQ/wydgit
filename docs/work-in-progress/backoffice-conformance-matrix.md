## Reading and counting this inventory

IDs below are stable audit IDs; existing CTX/STO/GAT/ACT/BOP/BOHTTP identifiers remain
source/test identifiers. Each row counts once. A supported site subset is deliberately
separate from wider-domain rows. `Implemented` means source behavior plus observable
positive/negative regression evidence, not just a declaration. Partial rows are not
fully conformant. Broader accepted targets with unresolved contract details remain
visible, even when not safe to implement in this assignment. No percentage is used.

Evidence levels: manifest/schema declaration → trusted runtime → actual installed
package → observable positive behavior → adversarial/lifecycle behavior. Tests named
in each row exercise the runtime; action/placement/HTTP suites use actual installations.
The packed run separately establishes distribution integration. Existing bounded
backend tests cannot establish canonical administrative Page delivery or OS isolation.
